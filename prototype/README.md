# Prototype

`index.html` is a single-file clickable demo of Our Kahani. It simulates two phones with a
toggle and keeps everything in memory. It has no server and does not encrypt its own data
(the Privacy screen shows the real AES-256-GCM lock in isolation). Use it as a behaviour and
copy reference only. Do not ship it.

Sample names in the demo are placeholders typed on the first screen.
